Several mailboxes, clearly apart

Every Gmail account you're signed in to in Chrome is found automatically and gets its own section in the list.

  • A name, a color and a sound for each

    Tell mailboxes apart at a glance, and by ear when a notification arrives.

  • One total, or one number per mailbox

    Show 15 on the icon, or 3/12 to see each mailbox separately.

  • Your labels, picked from a list

    Labels are read from Gmail itself, so you never have to type a label name.

Act without opening Gmail

Deal with new mail from wherever you are in Chrome.

  • Mark as read from the notification

    One click on the notification, and the message is marked as read in Gmail too.

  • Clear a whole mailbox

    Mark every unread message in a mailbox as read in one step, after a quick confirmation.

  • Open the right message

    Clicking a message opens it in the right Gmail account, reusing an open Gmail tab.

Private by design

Pigeon Post uses the Gmail session you already have in Chrome. There's no account to create and nothing extra to sign in to.

Talks only to mail.google.com

No server, no analytics, no ads and no tracking. Nothing is ever sent to the developer.

Mail stays in memory

Senders, subjects and snippets of unread mail are kept in memory only and cleared when Chrome closes.

Reads only what it needs

It reads Gmail's unread-mail feed, never full messages, and changes nothing except marking mail as read when you ask.

Open source

Every line is on GitHub under the GPL-3.0 license, so you can check exactly what it does.

Get started in a minute

  1. Add it to Chrome

    Install Pigeon Post from the Chrome Web Store.

  2. Stay signed in to Gmail

    Every Gmail account you're signed in to in Chrome is found on its own.

  3. Choose what matters

    The settings page opens right away. Pick what counts and what notifies you.
